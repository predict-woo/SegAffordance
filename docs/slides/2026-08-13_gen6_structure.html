Sequencing: the 3D point head reads the base condition; every articulation head reads [base condition, predicted point_3d] with gradient flowing — the same role coords_hat played classically, now in metric 3D.

What the outputs mean, per motion type

OutputPrismatic (drawer)Revolute (door)
$\hat{p}$ — interaction pointthe graspable element centroid (the handle) — same meaning for both types, never on the axis
$\hat{d}$ — directiontranslation direction (signed: drawer slides toward $+\hat{d}$)rotation axis direction (sign = right-hand rotation sense)
$\hat{q}$ — originmeaningless — translation has no axis location; head gets zero loss / zero gradientthe canonical hinge point $q^*$: the axis point closest to the interaction point — the axis in 3D space is $\hat{q} + t\hat{d}$; radius $= \mathrm{dist}(\hat{p}, \text{axis line})$, and at a perfect prediction simply $\lVert\hat{p}-\hat{q}\rVert$

Removed vs gen-5 (config-gated, code kept)

Twist head & se(3) parameterization · body metric · K=4 WTA bundles, annealing, selection logits, hyp-CE · screw consistency losses (gt + self) · type-from-$\lVert\omega\rVert$ eval · GT type-hint input · 2D point heatmap + soft-argmax + coord L1 (SF3D arm; OPD arms keep the 2D path) · frozen CLIP · cross-GT geometric loss (teacher forcing) — replaced by the all-predicted $L_{pp}$ (toggleable via geometric_loss) · GT-mask pooling at train time — replaced by detached predicted-mask pooling (toggleable via pool_with_predicted_mask). No GT tensor enters the model's forward pass anywhere.

Accepted risks on record: (1) single-hypothesis trajectory may re-hedge to the zero-motion baseline (the 0.018 signature) under opening-direction ambiguity — fallback: trajectory-only WTA. (2) Dropping the dense point heatmap removes localization supervision — fallback: Option A (3D head alongside the 2D machinery). (3) The all-predicted $L_{pp}$ is empirically untested (the July cross-GT-vs-pred-pred experiment pair never ran); mutually-consistent-but-wrong outputs are anchored only by each head's direct GT term. (4) Predicted-mask pooling has a cold start: condition features are ~global averages until the mask sharpens (historically ~1 epoch) — fallback is flipping pool_with_predicted_mask off.
